## 🎯 О проекте

Проект направлен на прогнозирование моментов отказа оборудования (котла) на основе анализа показаний 11 температурных датчиков поверхностей нагрева. Реализованы два подхода:

**Подход 1: Классическое машинное обучение (scikit-learn)**
- Создание физически обоснованных признаков (скорость деградации, коэффициент запаса прочности)
- Обучение и сравнение нескольких моделей (Random Forest, Gradient Boosting, Logistic Regression и др.)
- Физическое моделирование для прогноза времени до отказа

**Подход 2: Глубокое обучение (PyTorch)**
- Построение полносвязной нейронной сети с батч-нормализацией и дропаутом
- Обучение с ранней остановкой для предотвращения переобучения
- Генерация вероятностных прогнозов на будущий период

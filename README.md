## Обзор

**Задача:** Прогнозирование остановок котла БКЗ-500-140 по данным 11 датчиков температуры поверхностей нагрева.

**Решение:** 
- 🚀 Обучение на GPU (RTX 3060, CUDA 12.6)
- 🤖 6 ML моделей с GridSearch подбором гиперпараметров
- 🧠 3 нейросетевые архитектуры (DNN, Wide&Deep, Attention)
- 📊 Автовыбор лучшей модели (ML или NN) для каждого датчика
- 🌐 Веб-интерфейс на FastAPI с интерактивными графиками Plotly
- 📁 Загрузка CSV через Drag & Drop
- 📅 Прогноз на год вперед с помесячной сводкой

**Данные:** 5,738,001 записей, 2013-2018 гг, 10-минутные интервалы, 11 датчиков температуры.

**Результат:** Средний AUC на тесте 2018 года = **0.9546**, средний F1 = **0.9055**.

## Быстрый старт

Следуйте этим шагам, чтобы развернуть проект на локальной машине:

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/
   ```

2. **Создать и активировать виртуальное окружение**
   ```bash
   python -m venv venv
   ```
   - Для Windows:
     ```bash
     venv\Scripts\activate
     ```
   - Для Linux/Mac:
     ```bash
     source venv/bin/activate
     ```

3. **Установить зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Поместить данные в корень проекта**
   - Переименуйте ваш файл данных в `temperature_data.csv` и поместите его в корень проекта:
   ```bash
   cp your_temperature_data.csv temperature_data.csv
   ```

5. **Обучить модели (Jupyter)**
   - Запустите Jupyter Notebook:
   ```bash
   jupyter notebook full.ipynb
   ```
   - Выполните все ячейки по порядку.

6. **Исправить нейросети для CPU**
   ```bash
   python fix_nn_models.py
   ```

7. **Запустить сервер**
   ```bash
   python main.py
   ```

8. **Открыть в браузере**
   - Перейдите по следующему адресу: [http://localhost:8000](http://localhost:8000)

### Как пользоваться

1. **Загрузите CSV файл**
   - Перетащите файл в зону загрузки или нажмите для выбора.
   - Поддерживаются файлы с колонками `Date_Time` и датчиками.

2. **Выберите датчик**
   - Из выпадающего списка доступных датчиков.

3. **Выберите модель**
   - 🏆 **Лучшая** — автоматический выбор ML или NN.
   - 🤖 **Только ML** — классические модели.
   - 🧠 **Только нейросеть** — глубокое обучение.

4. **Укажите период**
   - Дата начала и конца прогноза.

5. **Нажмите "Выполнить прогноз"**

## Модели и признаки

### ML модели (6 типов)

| Модель                | Параметры GridSearch                         | Особенности                 |
|----------------------|----------------------------------------------|-----------------------------|
| RandomForest         | n_estimators: [100,200], max_depth: [10,15]| Ансамбль деревьев           |
| LightGBM            | num_leaves: [31,63], lr: [0.05,0.1]       | GPU ускорение               |
| XGBoost             | max_depth: [4,6], lr: [0.05,0.1]           | Регуляризация               |
| GradientBoosting     | n_estimators: [100,200], max_depth: [4,6]  | Классический бустинг       |
| LogisticRegression    | C: [0.01,0.1,1.0]                          | L2 регуляризация            |
| ExtraTrees           | n_estimators: [100,200], max_depth: [10,15]| Быстрее RandomForest        |

### Нейросети (3 архитектуры)

| Архитектура        | Слои                            | Параметры                        |
|---------------------|----------------------------------|----------------------------------|
| SimpleDNN           | 128→64→32→16→1                   | BatchNorm, Dropout 0.3          |
| WideDeepNet         | Wide(16) + Deep(128→64→32)      | Комбинирование                  |
| AttentionNet        | Multi-head Attention (4 heads)   | LayerNorm                        |

### Признаки (22 признака, сдвинуты на 24ч)

**Темпоральные (14):**
- Циклические: `hour_sin/cos`, `month_sin/cos`, `dayofweek_sin/cos`
- Категориальные: `hour`, `month`, `quarter`, `dayofweek`
- Флаги: `is_weekend`, `is_heating_season`, `is_night`, `is_morning_peak`, `is_evening_peak`

**Деградации (7):**
- `D_cumulative` — индекс накопленной деградации (Ларсон-Миллер)
- `degradation_speed` — скорость деградации
- `D_ma_24h`, `D_ma_168h` — скользящие средние
- `D_trend_72h` — тренд деградации
- `epsilon` — коэффициент загрязнения

**Статистические (1):**
- `seasonal_anomaly` — отклонение от сезонной нормы

### Защита от Data Leak
Все признаки сдвинуты на `STEPS_FORWARD` (144 шага = 24 часа). Модель не видит текущую температуру, только историю.
